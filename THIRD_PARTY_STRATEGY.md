# Third-party strategy

- This starter is clean-room and does not include SolidPilot source.
- SolidPilot is useful as an architectural/reference benchmark, but its AGPL licensing must be evaluated before code reuse in a closed-source commercial product.
- text-to-cad is MIT-licensed and can be evaluated separately for generic CAD/agent skill ideas, subject to preserving required notices when code is reused.
- MecAgent is treated only as a public product/UX benchmark; do not copy proprietary implementation or assets.
- SOLIDWORKS is proprietary software; redistribution and use of interop components must follow Dassault Systèmes' applicable SDK/license terms.
